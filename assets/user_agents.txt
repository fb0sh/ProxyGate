# Built-in user agent pool for `proxygate getua` and `GET /api/v1/getua`.
#
# Desktop browsers only: Chrome, Edge, Firefox and Safari on Windows, macOS and
# Linux. No mobile user agents, on purpose.
#
# One user agent per line. Blank lines and lines starting with `#` are ignored,
# so these comments are never handed out.
#
# `getua` picks uniformly at random across every entry in this file. There is no
# rotation and no memory of previous picks: two calls in a row may return the
# same string, which is what "random" means here.
#
# This is a snapshot -- browser versions age. Refresh it now and then; keeping it
# at 100 entries is a convention, not a requirement.
